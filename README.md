# Egg Heist

A first-person, browser-based take on the Roblox steal-and-extract loop, built
from scratch: **107 hand-authored voxel pets, eleven biomes, one stat that gates
everything, and something enormous asleep beside every nest.**

> Sneak up to a guarded nest. Take the egg. The guardian wakes the instant you
> lift it. Now run — because the only thing that gets you home is the same
> number that let you in.

---

## What this is

The game is a first-person reinterpretation of *Steal An Egg*'s design, rebuilt
as an original web game. Nothing is copied from the source: every model is
generated from Python in Blender, every system is written from scratch in
TypeScript, and the economy was re-derived from a research pass whose findings
are kept in [`docs/REFERENCE-ANALYSIS.md`](docs/REFERENCE-ANALYSIS.md).

**Play:** `npm install && npm run dev`, then open `http://localhost:5173`.

| | |
|---|---|
| **Engine** | TypeScript + Three.js + Vite, no game framework |
| **Art** | 107 pets + 13 eggs, all generated by Python in Blender, exported as `.glb` |
| **World** | ~2,900 collision boxes across eleven biomes, procedurally laid out from a fixed seed |
| **Audio** | Fully synthesised at runtime — no audio files ship |
| **Tests** | 42 tests covering physics, the economy and the full steal→hatch loop |

## The loop

```
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │   train Speed ──▶ unlock a biome ──▶ climb to the nest      │
  │        ▲                                     │              │
  │        │                                     ▼              │
  │   buy a faster                          TAKE THE EGG        │
  │   treadmill                         (the guardian wakes)    │
  │        ▲                                     │              │
  │        │                                     ▼              │
  │      money ◀── pets pay per second ◀── RUN HOME ──▶ caught? │
  │                        ▲                     │        │     │
  │                        └── hatch ◀── deliver ┘   drop it,   │
  │                                                  12s to     │
  │                                                  grab it    │
  └─────────────────────────────────────────────────────────────┘
```

Five beats, always the same shape: **approach → climb → take → run → cross the
line.** Nothing in the game is allowed to interrupt that arc with a menu.

## Speed is the only key

The single best idea in the source design, kept intact: **one stat gates
everything.** There is no money price on a biome, no rebirth wall, no pet-power
check. Speed opens a zone, and Speed is also the only thing that gets you back
out of it — so "can I unlock this" and "can I survive this" are the same
question, and you are never handed content you cannot actually play.

Money never buys Speed directly. Money buys a faster treadmill, the treadmill
makes Speed, and Speed opens the next biome full of better-paying pets.

| # | Biome | Speed gate | Guardian |
|---|---|---:|---|
| 1 | Whisperpine Forest | 0 | Broodhen |
| 2 | Glasswater Lake | 900 | Pale Swan |
| 3 | Ashfang Dunes | 10K | Dune Scorpion |
| 4 | Verdant Snarl | 40K | Emerald Tiger |
| 5 | Hollowfrost Shelf | 170K | Rimebound Yeti |
| 6 | Emberfall Caldera | 700K | Cerberus |
| 7 | Abyss Ocean | 2.5M | Kraken |
| 8 | Fossil Basin | 18M | T‑Rex |
| 9 | Starfall Rift | 700M | Hollow Constellate |
| 10 | Cherry Blossom Terrace | 2.5B | Nine‑Tail Kitsune |
| 11 | Titan Temple | 7B | Nightflame |

Guardian speed is never a hardcoded number — it is stored as a *fraction of the
player's sprint at that biome's gate*. Player movement is logarithmic in Speed,
so a linear guardian table would silently overtake the player in the late
biomes and make them unwinnable. Expressing it as a ratio makes "you escape by
a hair at the gate, and overtraining buys comfort" true by construction at
every tier. There is a test that enforces exactly this.

Each biome's guardian is a **giant version of that biome's signature pet**, so
the thing that chased you through the Volcano is something you can eventually
own and stand on a pedestal.

## What changes in first person

The source game is third-person, which quietly hands the player three things
this version had to rebuild:

**You cannot see your own feet.** The game asks you to land on narrow platforms
constantly, so the viewmodel draws a pair of boots below the camera that fade
in as you look down. The movement is also deliberately forgiving where it
cannot be precise: coyote time, jump buffering, real air control, variable jump
height, and a generous ledge mantle.

**The egg covers the screen.** An egg held at chest height sits exactly where
you need to look to platform. So it tucks toward the shoulder *and* fades out
as you look down — either alone is not enough; tucking still occludes, and
fading alone reads as a bug.

**You cannot look over your shoulder.** The chase is the whole game, and it
comes from behind. That peripheral information is replaced with a threat
vignette, a directional arc that points at the nearest chaser, and fully
positional audio: guardian footfalls are panned and attenuated, so you can hear
which side it is closing from before you see it.

## The pets

107 pets across eleven biomes plus an event pool, on a ten-tier rarity ladder
(Common → Divine), each with independent **size** (Tiny → Titanic) and
**mutation** (Gold, Diamond, Rainbow, Void) rolls that multiply income. A
Titanic Rainbow Common can out-earn a plain Legendary, which is what makes a
hatch worth watching.

Every model is generated by Python in Blender — there is no `.blend` file to
lose and no manual export step. `tools/blender/lib/blockkit.py` is a boxy
creature-anatomy toolkit (`eyes`, `beak`, `snout`, `ears_pointed`,
`wings_membrane`, `tail`, …) and each biome has a generator module that uses it
to author its roster by hand:

```bash
npm run models                                        # build every model
python tools/build_models.py --biome volcano --sheet  # one biome + contact sheet
```

Pets are static meshes animated procedurally at runtime by node name. Rigging a
hundred creatures would have been the whole art budget; instead every model
exports the same named parts (`head`, `ear.L`, `wing.R`, `leg.FL`, `tail`, …)
and `src/fx/PetAnimator.ts` animates whichever ones exist. A pet with no legs
just skips the step cycle; one with wings gets a flap for free.

## Layout

```
src/
  core/       engine, fixed-step loop, input, AABB physics, GLB loading, synth audio
  player/     first-person controller, camera feel, viewmodel (egg + legs)
  ai/         guardian finite state machine
  world/      level builder, biome generation, safe zone, lighting
  game/       game state, the session loop, guardians, garden, saves
  data/       biomes, pets, rarity ladders, economy curves, progression
  ui/         HUD and panels
  fx/         procedural pet animation
tools/
  blender/    lib/ (kit + blockkit + petkit) and generators/ (one per biome)
  gen_pets.py generates src/data/pets.ts from the roster
tests/        physics, economy and gameplay-loop tests
docs/         design notes and the reference research
```

## Commands

```bash
npm run dev        # dev server
npm run build      # typecheck + production bundle
npm test           # 42 tests
npm run models     # rebuild every .glb from Blender
```

Building models needs Blender 4.x or 5.x on your `PATH` (or `BLENDER` set to
the executable). The game runs fine without it — the committed `.glb` files are
all you need to play.

## Notes on originality

The gameplay systems, economy shape and biome progression are modelled on
*Steal An Egg*; the implementation, art, world, audio and code are entirely
original. A handful of the source roster's pets are meme characters from
another franchise — those are replaced with original creations of the same
tier and theme (Branchwalker, Anglerkin, Dustpiper, Pineape, Chili Imp,
Ringhorn Bovid, Tarpitan, Abyssal Maja, Mallet Sentry, Peelfin, Bellug,
Mangowing, Cocoa Croc, and the whole Titan Temple roster). They are marked in
`docs/DESIGN.md`.
